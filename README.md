# 漢検 漢字帳（3級〜1級）

日本漢字能力検定（漢検）の 3級・準2級・2級・準1級・1級 に配当された漢字を、間隔反復と小テストで覚えるための漢字帳です。
HSK 単語帳と同じく、ビルド不要の静的サイトなので、ファイルをそのまま置けば公開できます。

- 収録: **4,720 字**
  - 3級 284 字・準2級 328 字・2級 185 字（2級までで常用漢字 2136 字がそろう）
  - 準1級 865 字・1級 3,058 字（常用漢字の外の字。JIS 第1・第2水準の字）
- 各字に 音読み・訓読み・部首と部首名・画数・筆順・意味・熟語と例文（4,834 文）
  - 3〜2級の音訓は常用漢字表のもの、準1級・1級は表外の音訓も含めたもの
  - 準1級・1級は、語の例が乏しい字には例文を載せていません（準1級 800 字・1級 1,481 字に例文あり）。
    例文のない字も、部首・画数・筆順の問題とカード学習には出ます
- **四字熟語 221 語**と**対義語・類義語 140 組**つき。字とは別に記録します
- 小テストは 8 形式：**読み／書き取り／送り仮名／部首／画数／筆順（何画目）／四字熟語／対義語・類義語**
- 記録はすべて利用者の端末内（localStorage）に保存。サーバーへは何も送りません
- 既定で出題されるのは 3級（284字）。ほかの級はホームや設定でいつでも追加できます

---

## 1. 手元で動かす

```
cd kanken-vocab
python -m http.server 8765
```

ブラウザで <http://127.0.0.1:8765/> を開きます。

`index.html` をダブルクリックして `file://` で開いても動きます（データを `fetch` せず
`<script>` で読む構成にしてあるため）。ただしオフライン保存（Service Worker）だけは
`http://` または `https://` でないと有効になりません。

## 2. 広告（Google AdSense）を出す

広告枠の位置と仕組みは HSK 単語帳と同じです（ホーム下部・一覧の末尾・小テストの結果の 3 か所。
フラッシュカードと問題を解く画面には入れていません）。

**初期状態では広告は止めてあります**（`js/ads.js` の `enabled: false`）。止めている間は、
枠の位置がわかるプレースホルダーが表示されます。

1. このサイトを公開したあと、AdSense の「サイト」にこのサイトの URL を追加して審査を受ける
   （発行者 ID は HSK 単語帳と同じ `ca-pub-8997874792161168` のまま使えます）
2. 承認されたら、`index.html` の AdSense 読み込みタグのコメントを外す
3. AdSense で「ディスプレイ広告」ユニットを 3 つ作り、`js/ads.js` の `slots` に ID を入れ、`enabled: true` にする
4. `sw.js` の `var CACHE = "kanken-vocab-v2";` の数字を 1 つ上げて再公開する

> AdSense のポリシー上、プライバシーポリシーの掲示が必要です。HSK 単語帳と同じ文面を流用し、
> このサイトにも置いてください。

## 3. 公開する

GitHub Pages・Netlify・Cloudflare Pages のどれでも、フォルダをそのまま置けば動きます
（手順は HSK 単語帳の README と同じです）。公開時に `tools/` `src/` `dev/` は不要ですが、
置いたままでも動作に影響はありません。

ファイルを更新して再公開するときは、`sw.js` の `CACHE` の版数を上げてください
（上げないと、既に開いた人の端末で古いファイルが使われ続けます）。

## 4. データの作り方と直し方

`data/*.js` は **`tools/build_data.py` が作るファイルなので、直接書き換えないでください**。
手で書くのは `src/` の TSV だけです。

```
python tools/fetch_sources.py   # 初回だけ。公開データを tools/.cache/ に取ってくる（約30MB）
python tools/build_data.py      # src/*.tsv と公開データから data/*.js を作る
python tools/build_data.py --sheet p1   # その級の字と音訓の一覧（例文を書くときの下書き用。準1級・1級は英語の意味も出る）
```

`build_data.py` は最後に「確認が必要な点」を一覧で出します。常用漢字表にない字・
見出しより上の級の字・常用音訓で読めない読み・誤答を 3 つ作れない語などを見つけたら知らせます。
`--strict` を付けると、1 件でもあれば失敗として終わります。
「お知らせ」は直さなくてよいもので、`--strict` でも失敗にしません（いま出る「衷 の画数」は、
元データの 10 画より KanjiVG の 9 画のほうが一般的な辞書と合うため、9 画を採っている旨のお知らせです。
準1級・1級にも同じ種類のお知らせが数件あります）。

### 字の熟語・例文を足す・直す

`src/kanji-3.tsv` / `kanji-p2.tsv` / `kanji-2.tsv` / `kanji-p1.tsv` / `kanji-1.tsv` の 1 行が 1 字です。

```
哀	あわれ・かなしい	哀歓|あいかん|人生の{哀歓}を描いた映画だ。	悲哀|ひあい|中年の{悲哀}がにじむ物語。	哀れむ|あわれむ|捨て猫を{哀れむ}。
```

| 列 | 意味 |
|----|------|
| 1 | 字 |
| 2 | 意味（カードの裏に出す短い説明） |
| 3〜 | `語|読み|例文`。例文の `{語}` の部分が問われる（読みの問題では傍線、書き取りではカタカナになる） |

- 3〜2級の語は**常用漢字表の音訓だけ**で読めるものにし、どの級でも**見出しの字より上の級の字を入れない**でください
  （ビルドで警告が出ます）。準1級・1級は表外の音訓（元データの KANJIDIC の音訓）で読めれば通ります
- 準1級・1級は、3 列目以降を空にすれば「語の例なし」の字になります
- 叔父（おじ）・硫黄（いおう）・蜻蛉（とんぼ）のような熟字訓や、元データに無い慣用の読み（億劫＝おっくう など）は、
  読みの頭に `*` を付けます（`叔父|*おじ|…`）
- 字ひとつ＋送り仮名の語（`哀れむ` など）を入れると、その字は送り仮名の問題にも出ます
- 学習記録は字（`k:哀`）に紐づけています。熟語や例文を直しても記録は切れません

### 四字熟語・対義語・類義語

`src/yoji.tsv`（`熟語<TAB>1字ごとの読み（・区切り）<TAB>意味`）と
`src/pairs.tsv`（`対 か 類<TAB>問う語<TAB>読み<TAB>答えの語<TAB>読み`）です。
どの級に出すかは、含まれる字のうち最も難しい字の級で自動的に決まります。

### 誤答の作り方

選択肢の誤答は `build_data.py` が作ります。

- **読み** — 形の似た字・同じ音符の字の音で読んだ形（該当→かくとう）、濁点・長音・促音を
  1 か所ずらした形（河畔→かばん）、送り仮名の同じ別の訓（慰める→しずめる）
- **書き取り** — 同じ音の字（同音異字）・同じ訓の字（同訓異字）・形の似た字・同じ部首の字に
  置き換えた形。**置き換えた結果が同じ読みで実在する語になる場合は外します**（正解と紛らわしいため）
- **送り仮名** — 区切りを前後にずらした形（哀れむ→哀む・哀われむ・哀）
- **部首** — その字を形づくる別の部品と、よく出る部首

乱数の種を固定しているので、何度作り直しても同じ誤答になります。

## 5. 動作確認

`dev/selftest.html` をサーバー経由で開くと、59 項目の自己診断が走り、
画面上に `RESULT 59/59 passed` と結果一覧が出ます。

```
python -m http.server 8765
# → http://127.0.0.1:8765/dev/selftest.html
```

全 4,720 字・全熟語について 8 形式の問題が組めること（誤答が 3 つ以上あり、正解と重ならないこと）、
筆順の画数が全字で画数と一致すること、学習の一巡、小テスト、一覧の検索、設定、筆順の表示までを確かめます。
**この端末の学習記録を消すので、普段使うブラウザでは開かないでください。**

`dev/preview.html` と `dev/frame.html` は、各画面をスマホ幅で確認するためのページです。
`dev/` はアプリ本体からは参照されません。

## 6. 学習の仕組み

- **フラッシュカード** — 表は字だけ。読みと意味を思い浮かべてからめくり、自己採点します。
  間隔反復（ライトナー箱式）は HSK 単語帳と同じで、`js/srs.js` の `INTERVALS` で間隔を変えられます
- **小テスト** — 設定で選んだ形式を混ぜて 10 問。ホームの「形式を選んで練習」からは 1 形式だけを 10 問。
  字を問う形式（読み〜筆順）は、間違えた字を要復習に戻します。正解しても箱は進めません
- **四字熟語・対義語・類義語** — 選んだ級のうち最も上の級までの語を出します（2 級の試験には
  3 級の字の熟語も出るため）。まだ出していない語・前回間違えた語を先に出します
- **筆順** — 画のデータは級ごとのファイル（3〜2級 約 650KB・準1級 約 740KB・1級 約 2.8MB）に分けてあり、
  筆順の画面や「何画目」の問題を開いたときに、必要な級のぶんだけ読み込みます
- **字のデータ** — `data/kanji.js`（3〜2級）・`kanji-p1.js`・`kanji-1.js` は起動時にすべて読み込みます
  （合わせて約 1.8MB。gzip 圧縮で配信されるホスティングなら転送量はその 3 割ほど）
- **連続日数** — 学習か小テストをその日に 1 回でも行うと加算します

## 8. 既知の制約

- **部首は康熙字典の分類（Kanjium による）**です。漢検の部首の分類とはごく一部の字で異なることがあります。
  端末で表示できない部首の字形（⺼ など）は、漢検でふつうに使う字形（月 など）に置き換えています
- **筆順は KanjiVG のもの**です。漢検は文部省「筆順指導の手びき」に従っており、ごく一部の字で
  異なる可能性があります
- **級の配当は Kanjium のデータ**（3〜2級は 2020 年度の配当改定後の字数と一致）によります。公開前に、
  漢検の公式の配当表とご自身でも照らし合わせてください
- **準1級・1級の字の範囲**は、Kanjium で準1級・1級とされた字から、常用漢字・人名用漢字の旧字体（國・亞 など）と、
  JIS 第1・第2水準に無い字体（俠・𠮟 など）を除いたものです（`build_kanji_table` の条件）。
  漢検の公式の対象字（約 3,000 字・約 6,000 字）とは、異体字の扱いなどで多少ずれます。
  1級には部首だけの字（丶・冂 など）や単位の国字（瓩・竍 など）も入っています
- **準1級・1級の音訓は KANJIDIC のもの**です。呉音・漢音などをすべて並べているため、
  漢検の辞典より読みが多く出る字があります
- **1級の例文は 3,058 字中 1,481 字のみ**です。語の例が確かに書ける字に絞りました。
  読み・書き取りの問題は例文のある字からだけ出ます
- 2 級の 𠮟・塡・剝・頰 は、常用漢字表の字体ではなく、端末で表示しやすい許容字体（叱・填・剥・頬）で
  出しています（詳細画面に注記があります。試験ではどちらで書いても正解です）
- 送り仮名は「送り仮名の付け方」の本則を正解にしています。「掛る」のような許容の形は誤答として出ます
- 試験は記述式ですが、このアプリは 4 択です。書いて覚える練習は紙と併用してください
- 例文・意味の説明は本アプリのための書き下ろしです。誤りや不自然な文が残っている可能性があるので、
  気づいたら `src/` を直して作り直してください
- 記録はブラウザごと・端末ごとです。端末間の同期や、履歴の消去からの復元はできません
- 準1級・1級の四字熟語は 58 語、対義語・類義語は 3〜2級の語のみです

```
index.html                 画面の器

js/store.js                学習記録の保存と読み出し
js/srs.js                  間隔反復（ライトナー箱式）
js/ads.js                  広告枠（ここだけ書き換えれば広告が出る）
js/strokes.js              筆順の読み込みと表示
js/app.js                  画面の組み立てと操作
data/kanji.js              漢字 3〜2級 797 字（build_data.py が作る）
data/kanji-p1.js           漢字 準1級 865 字（同上）
data/kanji-1.js            漢字 1級 3,058 字（同上）
data/jukugo.js             四字熟語・対義語・類義語（build_data.py が作る）
data/strokes*.js           筆順。級ごとに 3 ファイル（build_data.py が作る。必要なときだけ読み込む）
src/kanji-3.tsv など       手で書く熟語・例文・意味（級ごとに 5 ファイル）
src/yoji.tsv / pairs.tsv   手で書く四字熟語・対義語・類義語
tools/fetch_sources.py     公開データの取得
tools/build_data.py        data/*.js の生成と検査
icons/                     アイコンと、その生成スクリプト
dev/                       自己診断と画面確認用のページ（公開不要）
```
